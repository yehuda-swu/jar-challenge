# Make It Fit

A mobile classroom activity about priorities and the jar analogy.

## Publish
Create a public GitHub repository named jar-challenge. Upload index.html to the repository root. In Settings > Pages, select Deploy from a branch, main, / (root), then Save. Open the published URL shown by GitHub Pages.

## Classroom use
Ask students to try without hints. They can undo a move or empty their jar and try again. Putting all three rocks in first, then the six stones, then the twelve pebbles is a verified winning sequence. Starting with all pebbles, then stones, leaves insufficient room for all rocks. Other sequences may also work. Discuss the analogy after the challenge.

The game uses a simplified grid packing model rather than real physical simulation. All assets are contained in index.html. No accounts, data collection, libraries or external services are needed.
